## ✦ Features

<div align="center">

| | Feature | What it does |
|:---:|---|---|
| 👤 | Name generation | Generates first names, last names, and full names |
| 🔤 | Username generation | Creates unique-looking usernames with various styles |
| ⚤ | Gender filter | Filter names by male, female, or neutral |
| ➕ | Add sections | Add multiple name sections to the page at once |
| 📋 | One-click copy | Copy any name or username with a single click |
| 🌙 | Dark / Light mode | Toggle between dark and light themes |
| 🔔 | Toast notifications | Visual feedback when something is copied |

</div>

## ✦ Download & Run

**Step 1** .... Clone the repo

```bash
git clone https://github.com/0xnurrabby/Name-Generator
cd Name-Generator
```

**Step 2** .... Open in browser

```bash
start index.html
# No build or server needed
```

**Step 3** .... Generate names

---

## ✦ Setup

```
1. Clone the repo
2. Open index.html in any modern browser
3. No dependencies, no build step, no server required
4. Click the + button to add name sections
5. Use the Gender dropdown to filter
6. Click any name to copy it
7. Toggle the theme button in the top right for dark/light mode
```

---

## ✦ Project Structure

```
Name-Generator/
  index.html    ->  full app markup with templates
  script.js     ->  name/username generation logic, section management
  styles.css    ->  layout, card styles, dark/light theme
  data/         ->  name datasets (first names, last names, username parts)
  fonts/        ->  custom font files
```
